# 開発環境のセットアップ

## 全員共通

1. Git をインストールする
2. VS Code をインストールする
3. このリポジトリを clone する

   ```bash
   git clone <このリポジトリのURL>
   ```

4. Node.js 22 以上をインストールする（レビュー依頼ボットに使う）
5. チームからもらった `.env` を `tools/review-bot/.env` に置く。エージェントへの登録の仕方は `tools/review-bot/README.md`
