# 008: 成果物の見せ方は道具を決めず、目的だけを決める

- 日付：2026-11-26
- 決めた人：（PR のレビューで決める。提案はいうてぃー）

## 決めたこと

- 成果物を見てもらうときの道具や置き場所（ドライブの「05_レビュー」、ドキュメントの書式など）を決めない。`AGENTS.md` には、満たしてほしいことだけを書く。
- 満たしてほしいこと：動画・音・画面の動きは開いたその場で再生・操作できる、文章はみんなが編集できる場所に置く、見る人に新しいアカウントや準備を求めない。
- 感想の受け取り方はこの節では決めない（「フィードバックを速く回す」に従う）。

## 理由

- メンバーごとに使う AI が違い（Claude、Codex など）、できることも違う。特定の道具を前提にすると、その道具を使えない AI が動けなくなる。
- 試してみると、Google ドキュメントには動画や音を埋め込んで再生できず、ファイルへのリンクを1つずつ開くことになった。Google スライドも、AI からはドライブの動画や音声を入れられなかった。道具を決めても、見せたいものに合わないことがある。
- 今の例：動画・音・UI はその場で再生できる Web ページ（PR のプレビュー URL や、AI が作るページ）、文章は Google ドキュメント。ただし AI や道具が変われば、より良い形を選んでよい。

## 検討したほかの案

- ドライブの「05_レビュー」にドキュメントを作る（これまでの決まり）：動画・音が見づらい。
- Google スライドにまとめる：動画は YouTube なら入れられたが、ドライブの動画と音声は AI から入れられなかった。
- Claude の Artifacts に決める：見やすいが、Claude 以外の AI では作れない。共有の仕方によっては見る人に Claude のアカウントが要り、公開リンクではコメントできない。

## 影響（変わること・注意すること）

- 003・006 にある「ドライブの『05_レビュー』にドキュメントを作る」は、この決定で置き換わる。
- 「05_レビュー」フォルダを作る必要はなくなる。
